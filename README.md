# Weather App

A simple weather application built using Python's `tkinter` library for the GUI, `geopy` for geocoding, and `OpenWeatherMap` API for weather data. This app allows users to search for weather information of a city and displays local time, temperature, weather conditions, wind speed, humidity, description, and pressure.

## Features

- **City Search**: Enter a city name to fetch weather data.
- **Local Time**: Displays the local time of the selected city.
- **Weather Information**: Shows temperature, wind speed, humidity, weather description, and pressure.

## Requirements

- Python 3.x
- `tkinter` (usually included with Python)
- `requests`
- `geopy`
- `timezonefinder`
- `pytz`
